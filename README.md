# سامانه کاشف — دفتر هوشمند گزارش مأموریت

برنامه اندرویدی «کاشف» برای ثبت گزارش مأموریت، مدیریت افراد مشکوک، جستجوی چهره و نقشه نقاط آلوده.
کاملاً آفلاین (اینترنت فقط برای دریافت کاشی‌های نقشه هیبرید)، با رمزنگاری کامل دیتابیس و تصاویر.

## امکانات اصلی

- **ثبت گزارش مأموریت** با شماره گزارش پیوسته `م/تاریخ/0001` (بدون بازنشانی سالانه)
- **پلاک خودرو** به قالب `67 ایران 123 حرف 45` و **پلاک موتورسیکلت** به قالب `123 - 45678`
- **کد ملی ۱۰ رقمی** با بررسی فرمول + تکمیل خودکار نام و مشخصات از دیتابیس اولیه و سوابق
- **موبایل ایران** ۱۱ رقمی با پیشوند `09` و خطای inline
- **تقویم شمسی** با انتخاب‌گر تقویم + تایپ دستی همه تاریخ‌ها
- **تشخیص چهره آفلاین** (ML Kit + MobileFaceNet) با بررسی کیفیت، تراز چشم‌ها و جستجو در دیتابیس
- **نقشه هیبرید جاده/ماهواره** با کش آفلاین + **نقشه نقاط آلوده** (هفتگی/ماهانه/سالانه/همه، چندنوعی، رنگ و راهنما)
- **نقشه تمام‌صفحه** با خروجی **عکس PNG** و **PDF** (شامل راهنمای نقشه و نقاط آلوده)
- **افراد مشکوک** (با/بدون وسیله نقلیه، فقط وسیله نقلیه) + **جستجوی یکپارچه** با نشان‌های مبدأ
- **دیتابیس اولیه افراد** با ایمپورت CSV/JSON (۱۰۰۰+ رکورد) و تکمیل خودکار
- **اظهارات** اشخاص/تلفن‌ها/وسیله‌های نقلیه ذکرشده توسط مظنون
- **تصاویر** با پینوشت، تفکیک عکس صحنه از چهره/مدارک، نمایش مرکزی در PDF
- **خروجی PDF** با فونت‌های B Nazanin و B Titr، واترمارک، رمز PDF و اشتراک ZIP رمزدار
- **خروجی اکسل شاخص‌ها** (XLSX راست‌چین) و **پشتیبان‌گیری/انتقال** با ZIP رمزدار AES-256
- **امنیت:** SQLCipher کامل، رمزنگاری تصاویر، ضد اسکرین‌شات، قفل خودکار (حداقل ۵ ثانیه)، اثر انگشت، رمز فریب، بازیابی با سوالات امنیتی و کد ۱۶ کاراکتری آفلاین
- **تنظیمات به‌صورت زیرصفحه‌های مجزا** (مثل تنظیمات اندروید) + انتخاب **آیکون برنامه** از ۴ طرح داخلی یا عکس دلخواه (میانبر)
- **مدیریت‌کننده خطای سراسری:** در صورت کرش، برنامه خودکار به صفحه قفل برمی‌گردد و گزارش خطا نمایش داده می‌شود

## بیلد

### GitHub Actions (پیشنهادشده)
پوش کردن پروژه به گیت‌هاب و اجرای workflow `build-apk.yml` فایل `app-release.apk` را تولید می‌کند.
امضای برنامه با کلید ثابت `kashef.keystore` داخل پروژه انجام می‌شود تا نصب نسخه جدید روی نسخه قبلی
**بدون حذف برنامه قبلی و بدون از دست رفتن داده** انجام شود (آپدیت درجا مثل فروشگاه پلی).

### Android Studio
پروژه را در Android Studio باز کنید و روی Run بزنید. نیازمند JDK 17 و Android SDK 34 است.

## نکته مهم درباره آپدیت
برای آپدیت بدون حذف، امضای همه نسخه‌ها باید یکسان باشد. کلید `kashef.keystore` را نگه دارید و
در گیت‌هاب خصوصی نگه دارید. نسخه فعلی `versionCode = 3` و `versionName = "2.1"` است؛
برای هر نسخه جدید فقط `versionCode` را افزایش دهید.
